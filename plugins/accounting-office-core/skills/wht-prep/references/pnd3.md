# ภ.ง.ด.3 — ผู้ถูกหักเป็นบุคคลธรรมดา

ใช้เมื่อผู้รับเงิน (ผู้ถูกหักภาษี) เป็น **บุคคลธรรมดา คณะบุคคล หรือห้างหุ้นส่วนสามัญที่ไม่ใช่นิติบุคคล**
อ่าน `common-rules.md` ก่อนเสมอ

---

## Header (26 ช่อง)

```
ลำดับที่|เลขประจำตัวผู้เสียภาษี|สาขาที่|คำนำหน้าชื่อ|ชื่อ|ชื่อกลาง|ชื่อสกุล|อาคาร|เลขห้อง|ชั้นที่|หมู่บ้าน|เลขที่|หมู่ที่|ตรอก/ซอย|แยก|ถนน|ตำบล/แขวง|อำเภอ|จังหวัด|รหัสไปรษณีย์|วันเดือนปีที่จ่าย|ประเภทเงินได้|อัตราภาษี|จำนวนเงินที่จ่าย|จำนวนเงินภาษีที่หัก|เงื่อนไขการหัก
```

---

## กฎเฉพาะ ภ.ง.ด.3

| ช่อง | กฎ |
|---|---|
| `เลขประจำตัวผู้เสียภาษี` | คือ **เลขประจำตัวประชาชน 13 หลัก** ของผู้ถูกหัก |
| `สาขาที่` | บุคคลธรรมดาส่วนใหญ่ **เว้นว่าง** ใส่เฉพาะกรณีจดทะเบียนสาขา |
| `คำนำหน้าชื่อ` | `นาย` / `นาง` / `นางสาว` — ใส่คำเต็ม ไม่ใช่ `น.ส.` |
| `ชื่อ` / `ชื่อกลาง` / `ชื่อสกุล` | แยกคนละช่อง ชื่อกลางคนไทยมักเว้นว่าง |
| `ที่อยู่` (อาคาร…รหัสไปรษณีย์) | ใส่เท่าที่ปรากฏในเอกสาร ช่องที่ไม่มีให้เว้นว่าง **ห้ามเดา** |
| `ประเภทเงินได้` | ระบุตามเอกสาร เช่น `ค่าจ้างทำของ`, `ค่าบริการ`, `ค่าเช่า`, `ค่าวิทยากร` |
| `อัตราภาษี` | ตัวเลขล้วน — ตรวจความสมเหตุสมผลกับ `wht-rates.md` |

> **คำนำหน้าชื่อของคณะบุคคล/ห้างหุ้นส่วนสามัญ** ให้ใส่ตามที่ปรากฏ เช่น `คณะบุคคล`
> แล้วใส่ชื่อทั้งหมดในช่อง `ชื่อ` เว้น `ชื่อกลาง` และ `ชื่อสกุล` ว่าง
