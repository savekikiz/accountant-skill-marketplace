## วันที่: พ.ศ. vs ค.ศ.

หนังสือรับรองหัก ณ ที่จ่ายของไทยใช้ **พ.ศ.** และแบบที่ยื่นก็ใช้ พ.ศ.
ถ้าเอกสารเขียนปีเป็น ค.ศ. (บางระบบ ERP พิมพ์ออกมาเป็น ค.ศ.) ให้ **แปลงเป็น พ.ศ. ก่อนใส่ในตาราง**

```
พ.ศ. = ค.ศ. + 543
```

| ที่เห็นในเอกสาร | ตีความ | ใส่ในตาราง |
|---|---|---|
| `04/02/2569` | พ.ศ. เต็ม | `04/02/2569` |
| `04/02/2026` | ค.ศ. เต็ม | `04/02/2569` |
| `4/2/69` | พ.ศ. 2 หลัก | `04/02/2569` |
| `4/2/26` | **กำกวม** — อาจเป็น พ.ศ.2526 หรือ ค.ศ.2026 | **ถามผู้ใช้** |
| `02/04/2569` กับเอกสารภาษาอังกฤษ | อาจเป็น MM/DD | **ถามผู้ใช้ถ้าทั้งสองค่า ≤ 12** |

**ห้ามแปลงอัตโนมัติเมื่อกำกวม** — ผิดปี = ยื่นผิดงวด = เบี้ยปรับ

## เลขประจำตัวผู้เสียภาษี

1. ลบช่องว่าง ขีด และอักขระอื่นออกก่อน
2. ต้องได้ **13 หลักพอดี** — ถ้าไม่ครบ ห้ามเติมศูนย์เอง ให้เปิดภาพดูหรือถามผู้ใช้
3. ตรวจ checksum ตาม `../../ocr-review/references/tax-id-checksum.md`
4. หลักแรกช่วยยืนยันว่าแยกแบบถูก:
   - `0` = นิติบุคคล → มักเป็น **ภ.ง.ด.53**
   - `1`–`8` = บุคคลธรรมดา → มักเป็น **ภ.ง.ด.3**
   - เป็นแค่ตัวช่วย ไม่ใช่กฎตายตัว (คณะบุคคล ห้างหุ้นส่วนสามัญ ร้านค้าบุคคลธรรมดา ใช้เลขบัตรประชาชน แต่ยื่น ภ.ง.ด.3)

## ตรวจคณิตศาสตร์

```
ภาษีที่หัก ≈ จำนวนเงินที่จ่าย × (อัตราภาษี ÷ 100)
tolerance ±1 บาท สำหรับการปัดเศษ
```

**ฐานที่ใช้คำนวณ WHT คือยอด "ก่อน VAT" เสมอ** — ไม่ใช่ยอดรวม VAT
ถ้าคำนวณจากยอดรวม VAT แล้วตรงพอดี แปลว่าผู้จ่ายคำนวณผิด → flag ไว้ แจ้งผู้ใช้ **อย่าแก้ตัวเลขเอง**

ตัวอย่าง: ค่าบริการ 10,000 + VAT 700 = 11,700
```
ถูก : WHT = 10,000 × 3% = 300  → จ่ายจริง 11,400
ผิด : WHT = 11,700 × 3% = 351
```

## เกณฑ์ที่ต้องหักภาษี ณ ที่จ่าย

โดยทั่วไปต้องหักเมื่อการจ่ายเงิน **ตั้งแต่ 1,000 บาทขึ้นไป** ต่อครั้ง
หรือเมื่อรวมทั้งสัญญาถึง 1,000 บาท แม้จ่ายเป็นงวดย่อยที่แต่ละงวดไม่ถึงก็ตาม

ถ้าเจอใบที่ยอดต่ำกว่า 1,000 บาทแต่มีการหัก ให้บันทึกตามเอกสาร (หักเกินไม่ผิด แต่ควรทักผู้ใช้)
