# ภ.ง.ด.53 — ผู้ถูกหักเป็นนิติบุคคล

ใช้เมื่อผู้รับเงิน (ผู้ถูกหักภาษี) เป็น **บริษัท ห้างหุ้นส่วนนิติบุคคล มูลนิธิ หรือสมาคม**
อ่าน `common-rules.md` ก่อนเสมอ

---

## Header (24 ช่อง)

```
ลำดับที่|เลขประจำตัวผู้เสียภาษี|สาขาที่|คำนำหน้าชื่อ|ชื่อ|ชื่ออาคาร|ห้องเลขที่|ชั้นที่|หมู่บ้าน|เลขที่|หมู่ที่|ตรอก/ซอย|แยก|ถนน|ตำบล/แขวง|อำเภอ|จังหวัด|รหัสไปรษณีย์|วันเดือนปีที่จ่าย|ประเภทเงินได้|อัตราภาษี|จำนวนเงินที่จ่าย|จำนวนเงินภาษีที่หัก|เงื่อนไขการหัก
```

**ต่างจาก ภ.ง.ด.3 ตรงที่ไม่มีช่อง `ชื่อกลาง` และ `ชื่อสกุล`** — นิติบุคคลมีชื่อเดียว

---

## กฎเฉพาะ ภ.ง.ด.53

| ช่อง | กฎ |
|---|---|
| `เลขประจำตัวผู้เสียภาษี` | เลขทะเบียนนิติบุคคล 13 หลัก มักขึ้นต้นด้วย `0` |
| `สาขาที่` | **สำคัญ** — สำนักงานใหญ่ใส่ `00000` สาขาใส่เลข 5 หลักตามเอกสาร เช่น `00001` |
| `คำนำหน้าชื่อ` | `บริษัท` / `ห้างหุ้นส่วนจำกัด` / `ห้างหุ้นส่วนสามัญนิติบุคคล` / `มูลนิธิ` / `สมาคม` |
| `ชื่อ` | ชื่อนิติบุคคล **ไม่รวมคำนำหน้า แต่รวมคำท้าย** เช่น คำนำหน้า `บริษัท` + ชื่อ `ตัวอย่างเทรดดิ้ง จำกัด` |
| `ประเภทเงินได้` | เช่น `ค่าจ้างทำของ`, `ค่าบริการ`, `ค่าเช่า`, `ค่าโฆษณา`, `ค่าขนส่ง` |
| `อัตราภาษี` | ตรวจกับ `wht-rates.md` — มูลนิธิ/สมาคมใช้อัตราต่างจากบริษัท |

> **ช่อง `สาขาที่` เป็นจุดที่ผิดบ่อยที่สุด** — เอกสารเขียนว่า "สำนักงานใหญ่" ต้องแปลงเป็น `00000`
> ถ้าเอกสารไม่ระบุเลย ให้เว้นว่าง **อย่าใส่ `00000` เอง** แล้วแจ้งผู้ใช้ให้ตรวจ

## ตรวจก่อนส่ง

- [ ] ทุกบรรทัดมี 24 ช่อง (นับ `|` ได้ 23 ตัวต่อบรรทัด)
- [ ] ไม่มีบุคคลธรรมดาปนมา — ถ้าเจอ `นาย` / `นาง` / `นางสาว` ในช่อง `คำนำหน้าชื่อ` ต้องย้ายไป ภ.ง.ด.3
- [ ] `สาขาที่` เป็นตัวเลข 5 หลัก หรือเว้นว่าง — ไม่ใช่คำว่า `สำนักงานใหญ่`
- [ ] เลข 13 หลักผ่าน checksum ทุกแถว
- [ ] `จำนวนเงินภาษีที่หัก ≈ จำนวนเงินที่จ่าย × อัตราภาษี ÷ 100`
- [ ] อัตราที่ใช้กับมูลนิธิ/สมาคม ตรวจเป็นพิเศษ (10% ไม่ใช่ 3%)
