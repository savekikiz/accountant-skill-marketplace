## จุดที่ผิดบ่อยที่สุด

### 1. มูลนิธิ / สมาคม ใช้ 10% ไม่ใช่ 3%
ผู้รับที่เป็นมูลนิธิหรือสมาคม (ที่ไม่ใช่องค์การสาธารณกุศลตามประกาศกระทรวงการคลัง)
ถูกหักในอัตรา 10% — ตรวจช่อง `คำนำหน้าชื่อ` ใน ภ.ง.ด.53 ทุกครั้ง

### 2. ค่านายหน้าจ่ายให้บุคคลธรรมดา — ไม่ใช่ ภ.ง.ด.3
ค่านายหน้า/ค่าคอมมิชชั่นที่จ่ายให้บุคคลธรรมดาเป็นเงินได้ 40(2)
ต้องหักตาม **อัตราก้าวหน้า** ตามมาตรา 50(1) และยื่นใน **ภ.ง.ด.1** ไม่ใช่ ภ.ง.ด.3
ถ้าเจอใบแบบนี้ปนมาในกอง ให้แยกออกแล้วแจ้งผู้ใช้

### 3. ค่าขนส่ง 1% ใช้เฉพาะผู้ประกอบการขนส่ง
ค่าส่งของที่ผู้ขายเรียกเก็บรวมในบิลขายสินค้า ไม่ใช่ "ค่าขนส่ง" ที่ต้องหัก 1%
ถ้าผู้รับไม่ได้ประกอบกิจการขนส่ง อาจเข้าข่ายค่าจ้างทำของ 3% แทน

### 4. ฐานคำนวณคือยอดก่อน VAT
```
ค่าบริการ 10,000 + VAT 700 = 11,700
WHT = 10,000 × 3% = 300      (ไม่ใช่ 11,700 × 3% = 351)
จ่ายจริง = 11,700 − 300 = 11,400
```

### 5. เกณฑ์ 1,000 บาท
ต้องหักเมื่อจ่ายตั้งแต่ **1,000 บาท** ขึ้นไปต่อครั้ง หรือเมื่อรวมทั้งสัญญาถึง 1,000 บาท
แม้แบ่งจ่ายเป็นงวดย่อยที่แต่ละงวดไม่ถึงก็ตาม

### 6. ค่าเช่า vs ค่าบริการ
- เช่าพื้นที่เปล่า / เช่าอุปกรณ์ ผู้เช่าควบคุมการใช้เอง → **ค่าเช่า 5%**
- เช่าพร้อมคนควบคุม / เช่าห้องประชุมพร้อมบริการ → มักเป็น **ค่าบริการ 3%**
- ก้ำกึ่งบ่อย → ดู `mapping-overrides.md` ของลูกค้า ถ้าไม่มีให้ **ถามผู้ใช้**

## ใช้ตรวจย้อนกลับในงานกระทบยอด

เมื่อกระทบยอดธนาคารแล้วเจอผลต่างที่อธิบายไม่ได้ ให้ลองเทียบกับอัตราเหล่านี้:

| ผลต่างเท่ากับ | น่าจะเป็น |
|---|---|
| 1% ของยอดก่อน VAT | ค่าขนส่ง / ดอกเบี้ย / เบี้ยประกันวินาศภัย |
| 2% ของยอดก่อน VAT | ค่าโฆษณา |
| 3% ของยอดก่อน VAT | ค่าบริการ / ค่าจ้างทำของ / วิชาชีพอิสระ |
| 5% ของยอดก่อน VAT | ค่าเช่า / ค่ารางวัล |
| 10% ของยอดก่อน VAT | เงินปันผล หรือจ่ายให้มูลนิธิ/สมาคม |

**เป็นการอนุมานเท่านั้น** — ต้องยืนยันกับหนังสือรับรองหัก ณ ที่จ่ายตัวจริงเสมอ

## สิ่งที่ตารางนี้ไม่ครอบคลุม

- **e-Withholding Tax** — มีอัตราพิเศษที่ลดลงตามพระราชกฤษฎีกาซึ่งต่ออายุเป็นช่วงๆ
  **ต้องตรวจว่ายังมีผลอยู่หรือไม่ในปีภาษีที่ทำอยู่** ก่อนใช้
- เงินได้ 40(1) เงินเดือน และ 40(2) บางประเภท → ยื่น **ภ.ง.ด.1 / ภ.ง.ด.1ก** คนละแบบกัน
- การจ่ายไปต่างประเทศ → **ภ.ง.ด.54** และ **ภ.พ.36** (อัตราตามอนุสัญญาภาษีซ้อน)
- ผู้จ่ายที่เป็นส่วนราชการ (หัก 1% ตามมาตรา 69 ทวิ) — คนละกลไกกับ ท.ป.4/2528
- กิจการที่ได้รับสิทธิ BOI หรือยกเว้นภาษีตามกฎหมายเฉพาะ
- ผู้รับที่เป็นองค์การสาธารณกุศลตามประกาศกระทรวงการคลัง (ได้รับยกเว้นการหัก)

ทุกกรณีข้างต้น **ให้หยุดและถามผู้ใช้** อย่าใส่อัตราเอง
