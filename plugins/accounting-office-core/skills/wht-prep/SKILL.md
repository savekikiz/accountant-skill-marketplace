# เตรียมข้อมูล ภ.ง.ด.3 / ภ.ง.ด.53

อ่านหนังสือรับรองการหักภาษี ณ ที่จ่ายตามมาตรา 50 ทวิ แล้วออกเป็นตารางพร้อมนำเข้าโปรแกรมยื่นแบบ
**เตรียมข้อมูลอย่างเดียว ไม่ยื่นแบบให้**

---

## กฎบังคับ (ทุก skill ในชุดนี้ใช้เหมือนกัน)

1. **ทำงานเฉพาะในโฟลเดอร์ลูกค้าที่ผู้ใช้ระบุ** ห้ามอ่านหรือเขียนโฟลเดอร์ลูกค้ารายอื่น
2. **อ่าน `client-profile.md` ก่อนเริ่มงานทุกครั้ง** ถ้าไม่มี ให้หยุดแล้วบอกผู้ใช้ให้รัน `/new-client` ก่อน
3. **ก่อน action ที่เขียนข้อมูลเข้า ERP** ต้องแสดงชื่อบริษัทและเลขผู้เสียภาษีของบริษัทปลายทางใน ERP แล้วเทียบกับ `client-profile.md` — ถ้าไม่ตรง **หยุดทันที**
4. **สร้างเอกสารใน ERP เป็นสถานะรออนุมัติเท่านั้น** ห้ามอนุมัติ ห้ามบันทึกรับชำระ ห้าม void ห้ามลบ
5. **ใส่ชื่อ plugin และเลขเวอร์ชันไว้ในหัวทุกไฟล์ที่สร้าง** เช่น `accounting-office-core v1.0.0 — 2569-09-16`

---

## แยกแบบให้ถูกก่อนอย่างอื่น

| ผู้ถูกหักภาษี | แบบที่ยื่น | อ่านต่อ |
|---|---|---|
| บุคคลธรรมดา / คณะบุคคล / ห้างหุ้นส่วนสามัญที่ไม่ใช่นิติบุคคล | **ภ.ง.ด.3** | `references/pnd3.md` |
| บริษัท / ห้างหุ้นส่วนนิติบุคคล / มูลนิธิ / สมาคม | **ภ.ง.ด.53** | `references/pnd53.md` |

> **ห้ามรวมสองแบบไว้ในไฟล์เดียวกัน** — column ไม่เหมือนกันและยื่นคนละแบบ
> ถ้าในกองเอกสารมีทั้งสองประเภท ให้แยกกองก่อนแล้วออกเป็น 2 ไฟล์

กฎที่ใช้ร่วมกันทั้งสองแบบ (รูปแบบวันที่ ตัวเลข ช่องว่าง) → `references/common-rules.md`
อัตราภาษีและประเภทเงินได้ → `references/wht-rates.md`

## ขั้นตอนการทำงาน

### Step 1 — โหลดบริบท

1. อ่าน `client-profile.md` → **ลูกค้ารายนี้คือ "ผู้มีหน้าที่หักภาษี" (ผู้จ่ายเงิน)**
2. เลขผู้เสียภาษีของลูกค้าต้องตรงกับช่อง "ผู้มีหน้าที่หักภาษี ณ ที่จ่าย" ในเอกสารทุกใบ
   ถ้าเจอใบที่ไม่ตรง → **แยกออกมาแจ้งผู้ใช้ อย่าใส่ในตาราง** (อาจเป็นเอกสารของลูกค้ารายอื่นปนมา)
3. อ่าน `mapping-overrides.md` — อาจมีอัตราที่ตกลงกันไว้เฉพาะลูกค้ารายนี้

### Step 2 — คัดแยกกองเอกสาร

อ่านเอกสารทุกใบใน `<งวด>/source-docs/` (หรือโฟลเดอร์ที่ผู้ใช้ระบุ) แล้วแยกเป็น 3 กอง:
ภ.ง.ด.3 · ภ.ง.ด.53 · **อ่านไม่ออก/ไม่ใช่เอกสาร WHT**

รายงานจำนวนแต่ละกองให้ผู้ใช้เห็นก่อนเริ่มสกัด

> อ่านได้ประมาณ 20 หน้าต่อครั้ง ถ้ามากกว่านั้นให้แบ่งเป็นชุดแล้วบอกผู้ใช้

### Step 3 — สกัดข้อมูล

ทำตาม `references/common-rules.md` แล้วดู column ที่ต้องใช้ใน `references/pnd3.md` หรือ `references/pnd53.md`

**ห้ามเดาตัวเลขเด็ดขาด** — ถ้าอ่านไม่ออก ให้เว้นว่างแล้วระบุลำดับที่กับส่วนที่อ่านไม่ออก
ตัวเลขที่เดาแล้วดูเรียบร้อย อันตรายกว่าช่องว่างที่เห็นชัดว่าต้องเติม

### Step 4 — ตรวจก่อนส่ง

- [ ] จำนวนแถว (ไม่นับ header) = จำนวนใบในกองนั้น
- [ ] เลขผู้เสียภาษี 13 หลักครบทุกแถว ไม่มีขีด และ **ผ่าน checksum** (`../ocr-review/references/tax-id-checksum.md`)
- [ ] วันที่รูปแบบ `DD/MM/YYYY` ปี **พ.ศ.** และอยู่ในงวดที่ยื่น
- [ ] ตัวเลขเงินไม่มี comma
- [ ] ช่องว่างคือว่างจริง ไม่มี `-` หรือ `N/A`
- [ ] `ภาษีที่หัก ≈ จำนวนเงินที่จ่าย × อัตราภาษี` (คลาดเคลื่อนได้จากการปัดเศษ)
      ถ้าไม่ตรง → **ไม่ใช่แก้ตัวเลขให้ตรง** แต่ให้ flag ไว้ว่าเอกสารต้นฉบับอาจคำนวณผิด
- [ ] เลขผู้เสียภาษีของผู้หัก = เลขในระบบตาม `client-profile.md` ทุกใบ

### Step 5 — ออกไฟล์และสรุป

บันทึกที่ `<งวด>/output/pnd3-<งวด>.txt` และ/หรือ `pnd53-<งวด>.txt`
บรรทัดแรกของไฟล์เป็น comment กำกับที่มา:
```
# accounting-office-core v1.0.0 | <ชื่อลูกค้า> | งวด <งวด> | สร้างเมื่อ <วันที่>
```
> ถ้าโปรแกรมยื่นแบบไม่รับบรรทัด comment ให้บันทึกเป็น 2 ไฟล์:
> ไฟล์ข้อมูลล้วนสำหรับนำเข้า และไฟล์ `.md` กำกับที่มาไว้ข้างกัน

สรุปในแชต:
```
ภ.ง.ด.3  : N ใบ | ยอดจ่ายรวม X บาท | ภาษีหักรวม X บาท
ภ.ง.ด.53 : N ใบ | ยอดจ่ายรวม X บาท | ภาษีหักรวม X บาท
อ่านไม่ออก/ต้องตรวจมือ : N ใบ  (ระบุว่าใบไหน ส่วนไหน)

กำหนดยื่น: ภายในวันที่ 7 ของเดือนถัดไป (e-Filing ขยายเป็นวันที่ 15)
```

## ข้อจำกัดและสิ่งที่ผู้ใช้ต้องตรวจเอง

- **ผลลัพธ์ทุกรายการต้องถูกตรวจทานโดยผู้ทำบัญชีก่อนยื่น** — skill นี้เป็นตัวช่วยกรอกข้อมูล ไม่ใช่ผู้รับผิดชอบความถูกต้อง
- **ไม่ตรวจว่าอัตราที่หักมาถูกต้องตามกฎหมายหรือไม่** — สกัดตามที่ปรากฏในเอกสาร
  ถ้าผู้จ่ายหักผิดอัตรามาแต่ต้น ผลลัพธ์จะผิดตาม (ดู `references/wht-rates.md` เพื่อตรวจเอง)
- ไม่ตรวจว่ายื่นครบทุกใบหรือไม่ — ถ้าเอกสารหายไปจากกอง skill ไม่มีทางรู้
- ไม่กระทบยอดกับบัญชีแยกประเภทภาษีหัก ณ ที่จ่ายค้างจ่าย
- **ไม่เชื่อมต่อ e-Filing และไม่ยื่นแบบให้**
- ไม่ครอบคลุม ภ.ง.ด.1 / 1ก (เงินเดือน), ภ.ง.ด.2 (ดอกเบี้ย เงินปันผล บุคคลธรรมดา),
  ภ.ง.ด.54 และ ภ.พ.36 (จ่ายไปต่างประเทศ)
- เอกสารมีเลขประจำตัวผู้เสียภาษีและชื่อ-ที่อยู่บุคคล ซึ่งเป็นข้อมูลส่วนบุคคลตาม PDPA
