# กฎ VAT ที่ใช้ตรวจผล OCR

ตรวจสอบล่าสุด: **2026-09-16** · ปีภาษี **2569**
กฎเหล่านี้เปลี่ยนตามพระราชกฤษฎีกาและประกาศอธิบดีเป็นระยะ
**ก่อนใช้กับงวดอื่น ให้ตรวจอัตราและกำหนดเวลาปัจจุบันที่ rd.go.th ก่อน**

---

## 1. อัตราภาษี

| กรณี | อัตรา | อ้างอิง |
|---|---|---|
| อัตราทั่วไป (ลดโดยพระราชกฤษฎีกา ต่ออายุเป็นรายปี) | **7%** | ป.รัษฎากร ม.80 + พ.ร.ฎ. ลดอัตรา |
| ส่งออก / บริการที่ใช้ในต่างประเทศ | 0% | ม.80/1 |
| กิจการที่ได้รับยกเว้น (เช่น ขนส่งในประเทศ การศึกษา เกษตรขั้นต้น) | ยกเว้น | ม.81 |

> **7% นี้รวมภาษีท้องถิ่นแล้ว** (VAT 6.3% + ภาษีท้องถิ่น 0.7%)
> ใบกำกับภาษีบางฉบับแยกบรรทัดให้เห็น — อย่านับซ้ำ

### ใช้ตรวจ
```
VAT_MATH : |ยอดก่อน VAT × 0.07 − VAT| ≤ 0.02   → ผ่าน
VAT_SUM  : |ยอดก่อน VAT + VAT − ยอดรวม| ≤ 0.02 → ผ่าน
```
tolerance 0.02 บาท เผื่อการปัดเศษสตางค์ ไม่ใช่เผื่อ OCR อ่านผิด

### ถอดยอดเมื่อเอกสารระบุราคารวม VAT แล้ว
```
ยอดก่อน VAT = ยอดรวม ÷ 1.07
VAT         = ยอดรวม − ยอดก่อน VAT
```
**อย่าใช้ `ยอดรวม × 0.07`** — ได้ค่าเกินจริงประมาณ 7%

## 2. ประเภทใบกำกับภาษี

| ประเภท | ขอคืนภาษีซื้อได้ | อ้างอิง |
|---|---|---|
| ใบกำกับภาษีเต็มรูป | ✅ ได้ | ม.86/4 |
| ใบกำกับภาษีอย่างย่อ | ❌ **ไม่ได้** | ม.86/6 ประกอบ ม.82/5(6) |
| ใบเสร็จรับเงินที่ไม่ใช่ใบกำกับภาษี | ❌ ไม่ได้ | — |
| ใบเพิ่มหนี้ / ใบลดหนี้ | ✅ ปรับปรุงภาษีซื้อ | ม.86/9, ม.86/10 |

**ใบกำกับภาษีอย่างย่อ** = ที่ออกจากเครื่องบันทึกเงินสดของร้านค้าปลีก
(7-Eleven, ร้านสะดวกซื้อ, ปั๊มน้ำมัน) มักไม่มีชื่อ-ที่อยู่ผู้ซื้อ
→ flag `VAT_ABBREV` ถ้าผลลัพธ์ปลายทางคือการขอคืนภาษีซื้อ

### รายการที่ใบกำกับภาษีเต็มรูปต้องมี (ม.86/4)
1. คำว่า "ใบกำกับภาษี" ชัดเจน
2. ชื่อ ที่อยู่ และเลขประจำตัวผู้เสียภาษีของ **ผู้ขาย**
3. ชื่อ ที่อยู่ และเลขประจำตัวผู้เสียภาษีของ **ผู้ซื้อ**
4. หมายเลขลำดับของใบกำกับภาษี (และเล่มที่ ถ้ามี)
5. ชื่อ ชนิด ประเภท ปริมาณ และมูลค่าของสินค้าหรือบริการ
6. จำนวน VAT **แยกออกจากมูลค่าสินค้าอย่างชัดแจ้ง**
7. วัน เดือน ปี ที่ออกใบกำกับภาษี
8. ระบุ "สำนักงานใหญ่" หรือ "สาขาที่ …" ทั้งฝั่งผู้ขายและผู้ซื้อ

ข้อ 6 คือข้อที่ทำให้ `VAT_MATH` ตรวจได้ — ถ้าเอกสารไม่แยก VAT
แปลว่าอาจไม่ใช่ใบกำกับภาษีเต็มรูป ให้ flag ไว้

## 3. ภาษีซื้อที่ขอคืนไม่ได้ (ม.82/5)

flag ไว้ให้ผู้ทำบัญชีตัดสิน — **skill ไม่ตัดสินเอง**

| กรณี | เหตุผล |
|---|---|
| ไม่มีใบกำกับภาษี หรือมีแต่ไม่ถูกต้องตาม ม.86/4 | ม.82/5(1)(2) |
| ใบกำกับภาษีอย่างย่อ | ม.82/5(6) ประกอบประกาศอธิบดี |
| ค่ารับรอง | ม.82/5(4) |
| รถยนต์นั่ง/รถโดยสารไม่เกิน 10 ที่นั่ง รวมค่าน้ำมันและค่าซ่อม | ม.82/5(6) + ประกาศอธิบดี ฉบับที่ 42 |
| ภาษีซื้อที่ไม่เกี่ยวกับการประกอบกิจการ | ม.82/5(3) |
| ใบกำกับภาษีที่ออกโดยผู้ไม่มีสิทธิออก | ม.82/5(5) |

## 4. กำหนดเวลา

| เรื่อง | กำหนด |
|---|---|
| ยื่น ภ.พ.30 | ภายในวันที่ **15** ของเดือนถัดไป |
| ยื่นผ่าน e-Filing | ขยายเพิ่มอีก **8 วัน** (ตามประกาศกระทรวงการคลังที่ใช้อยู่) |
| ขอคืนภาษีซื้อย้อนหลัง | ภายใน **6 เดือน** นับแต่เดือนภาษีที่ระบุในใบกำกับภาษี |
| เก็บเอกสารประกอบการลงบัญชี | **5 ปี** (พ.ร.บ.การบัญชี ม.14) |

> กฎ 6 เดือน คือเหตุผลที่ flag `DATE_PERIOD` **ไม่ใช่ความผิด** — ใบเดือน ส.ค.
> ที่เพิ่งได้ในเดือน ก.ย. ยังนำมาขอคืนได้ แค่ต้องบันทึกให้ถูกเดือนภาษี

## 5. กับดักคณิตศาสตร์ที่เจอบ่อย

| อาการ | สาเหตุจริง | ทำอย่างไร |
|---|---|---|
| `ยอดก่อน VAT × 1.07 ≠ ยอดรวม` แต่เอกสารดูปกติ | มีสินค้า Non-VAT ปนในใบเดียวกัน | ดูช่อง "มูลค่าที่ยกเว้น/ไม่มีภาษี" ก่อน flag |
| VAT น้อยกว่า 7% ประมาณเล็กน้อย | มีส่วนลดท้ายเอกสาร คำนวณ VAT หลังหักส่วนลด | ใช้ยอดหลังหักส่วนลดเป็นฐาน |
| VAT เท่ากับ 7% ของยอดรวม (ไม่ใช่ยอดก่อน VAT) | คนออกเอกสารคำนวณผิดเอง | flag `VAT_MATH` แล้วแจ้งผู้ใช้ — ไม่ใช่ OCR ผิด |
| ยอดต่าง 0.01–0.02 บาท | ปัดเศษสตางค์ | อยู่ใน tolerance ปล่อยผ่าน |
| ยอดต่างเท่ากับ 1%, 2%, 3%, 5% ของยอด | นั่นคือ **ภาษีหัก ณ ที่จ่าย** ไม่ใช่ VAT ผิด | ดู `../../wht-prep/references/wht-rates.md` |

## ข้อจำกัด

- เอกสารนี้เป็น **ตัวช่วยตรวจเชิงกลไก** ไม่ใช่คำวินิจฉัยทางภาษี
- ไม่ครอบคลุมกิจการที่มีทั้งรายได้ VAT และรายได้ยกเว้น VAT (ต้องเฉลี่ยภาษีซื้อตาม ม.82/6)
- ไม่ครอบคลุม ภ.พ.36 (นำส่ง VAT แทนผู้ประกอบการต่างประเทศ) และบริการอิเล็กทรอนิกส์จากต่างประเทศ
- ไม่ครอบคลุมธุรกิจนำเข้า-ส่งออกที่มีใบขนสินค้า
- **อัตรา 7% มาจากพระราชกฤษฎีกาที่ต่ออายุเป็นรายปี** — ถ้าปีภาษีที่ทำอยู่ไม่ใช่ 2569 ให้ตรวจก่อนเสมอ
