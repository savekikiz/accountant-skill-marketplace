# สรุปปิดงวด + draft อีเมลขอเอกสาร

รวมผลจากงานทุกขั้นในงวดนี้ (OCR, vouch, กระทบยอด, WHT, การบันทึกเข้า ERP)
แล้วสรุปว่าปิดงวดได้หรือยัง ขาดอะไร และร่างอีเมลขอเอกสารให้

เป้าหมายที่ผู้ใช้ระบุ: `$ARGUMENTS`

ใช้ skill `close-report` — ทำตามขั้นตอนใน SKILL.md ทุกข้อ

## ก่อนเริ่ม
1. ถ้าไม่ระบุโฟลเดอร์ลูกค้า/งวด → **ถามก่อน**
2. อ่าน `client-profile.md` และไฟล์ผลลัพธ์ทั้งหมดใน `<งวด>/output/`

## ข้อห้าม
- **ห้ามส่งอีเมล** — สร้างเป็นไฟล์ร่างเท่านั้น ให้ผู้ใช้อ่าน แก้ และกดส่งเอง
  (🔒 hook บล็อก tool ส่งอีเมลและคำสั่งส่งเมลทาง Bash ไว้แล้ว แต่ไฟล์ร่างต้องมีคำว่า
  "ยังไม่ได้ส่ง" ในหัวไฟล์ด้วย)
- ห้ามสรุปว่า "ปิดงวดได้" ถ้ายังมีรายการค้างที่ยังไม่มีคำอธิบาย
  (🔒 hook เตือนถ้าไฟล์ขึ้น `✅ พร้อมปิดงวด` ทั้งที่ยังมีผลต่างไม่เป็นศูนย์หรือขั้นที่ยังไม่ได้ทำ
  — เป็นแค่คำเตือน การตัดสินว่าอธิบายรายการค้างได้ครบหรือยังเป็นหน้าที่ของคุณ)
