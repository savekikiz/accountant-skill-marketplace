# Vouch ค่าใช้จ่าย

ตรวจว่ารายการค่าใช้จ่ายที่บันทึกไว้ มีเอกสารต้นฉบับรองรับจริงหรือไม่

เป้าหมายที่ผู้ใช้ระบุ: `$ARGUMENTS`

ใช้ skill `vouch-expense` — ทำตามขั้นตอนใน SKILL.md ทุกข้อ

## ก่อนเริ่ม
1. ถ้าไม่ระบุโฟลเดอร์ลูกค้า/งวด → **ถามก่อน**
2. อ่าน `client-profile.md` และ `mapping-overrides.md`
3. ยืนยัน column mapping ของไฟล์ Excel กับผู้ใช้ก่อน match

## เมื่อทำเสร็จ
สรุปจำนวนแต่ละสถานะ + ยอดเงินที่ยังหาเอกสารไม่เจอ + assertion ที่ถูกละเมิด
