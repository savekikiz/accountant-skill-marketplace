# กระทบยอดธนาคาร

Match รายการ GL เงินฝากธนาคาร กับ Bank Statement ออกผลเป็น Excel พร้อมสถานะรายบรรทัด

เป้าหมายที่ผู้ใช้ระบุ: `$ARGUMENTS`

ใช้ skill `bank-reconcile` — ทำตามขั้นตอนใน SKILL.md ทุกข้อ

## ก่อนเริ่ม
1. ถ้าไม่ระบุโฟลเดอร์ลูกค้า/งวด → **ถามก่อน**
2. อ่าน `client-profile.md` และ `mapping-overrides.md`
3. ไฟล์ที่ต้องมี: GL เงินฝาก และ statement ใน `<งวด>/bank/`
   ถ้าลูกค้ามีหลายบัญชีธนาคาร ให้ถามว่าจะกระทบยอดบัญชีไหน — **ทำทีละบัญชี**

## เมื่อทำเสร็จ
สรุป % ที่ match ได้ + รายการค้างกระทบยอดที่ต้อง investigate + ยอดผลต่างคงเหลือ
