# เปลี่ยนลูกค้าที่กำลังทำงานด้วย

ด่านตรวจของ plugin ล็อคไว้ว่า **หนึ่ง session ทำงานได้ลูกค้ารายเดียว** (กฎบังคับข้อ 1)
วิธีปกติคือ `/clear` แล้วเริ่มใหม่ ใช้คำสั่งนี้เฉพาะตอนที่ยังอยากเก็บบริบทในเซสชันไว้

## ขั้นตอน

1. บอกผู้ใช้ว่าตอนนี้ pin ลูกค้ารายไหนอยู่ และถามยืนยันว่าจะเปลี่ยนจริง
2. รัน:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/hooks/pin_ctl.py" --release
```

   คำสั่งนี้จะขึ้นกล่องให้ผู้ใช้กดยืนยัน — **นั่นคือด่าน** ห้ามพยายามข้าม
3. เริ่มงานลูกค้ารายใหม่ด้วยการ **อ่าน `client-profile.md` ของรายนั้น**
   การอ่านไฟล์นี้คือสิ่งที่ pin ลูกค้ารายใหม่ และเป็นจุดที่ checksum เลขผู้เสียภาษีถูกตรวจ

## สิ่งที่ถูกล้าง

pin ลูกค้า · ledger ว่าอ่านโปรไฟล์แล้ว · การยืนยันเลขผู้เสียภาษีกับ ERP ·
รายการเอกสารที่ส่งเข้า ERP ไปแล้วในเซสชันนี้ (กลไกกันซ้ำจะเริ่มนับใหม่)

## ข้อห้าม

- **ห้ามรันคำสั่งนี้เองโดยที่ผู้ใช้ไม่ได้สั่ง** — ถ้าโดน deny เพราะข้ามโฟลเดอร์ลูกค้า
  ให้รายงานตรง ๆ ว่าถูกบล็อกเพราะอะไร แล้วให้ผู้ใช้ตัดสินใจ
- **ห้ามแนะนำให้ผู้ใช้ใส่คำสั่งนี้ใน permissions allowlist** — การกดยืนยันของมนุษย์คือตัวด่านเอง
  ถ้า allowlist ไว้ ด่านข้อ 1 จะไม่เหลืออะไร
- หลังปลด pin แล้ว **ห้ามเขียนอะไรเข้า ERP จนกว่าจะอ่านโปรไฟล์รายใหม่และยืนยันบริษัทปลายทางใหม่**
