# ตรวจผล OCR

ตรวจไฟล์ผล OCR ในงวดที่ระบุ หาแถวที่ข้อมูลผิด/ขาด/น่าสงสัย แล้วออกเป็น `exceptions.xlsx`
ให้ทีมแก้มือก่อนนำไปใช้ต่อ

เป้าหมายที่ผู้ใช้ระบุ: `$ARGUMENTS`

ใช้ skill `ocr-review` — ทำตามขั้นตอนใน SKILL.md ทุกข้อ

## ก่อนเริ่ม
1. ถ้าผู้ใช้ไม่ได้ระบุโฟลเดอร์ลูกค้าและงวด → **ถามก่อน อย่าเดา อย่าไล่สแกนทั้งเครื่อง**
2. อ่าน `client-profile.md` ของลูกค้ารายนั้น
3. อ่าน `mapping-overrides.md` ถ้ามี

## เมื่อทำเสร็จ
สรุปในแชตว่า: อ่านมากี่ใบ / ผ่านกี่ใบ / ต้องแก้มือกี่ใบ / ไฟล์ผลอยู่ที่ไหน
และชี้ 3 ประเด็นแรกที่ควรแก้ก่อน
