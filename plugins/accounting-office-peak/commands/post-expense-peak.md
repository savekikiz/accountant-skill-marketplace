# บันทึกค่าใช้จ่ายเข้า PEAK

นำรายการที่ **ผ่านการตรวจแล้ว** ไปสร้างเป็นเอกสารค่าใช้จ่ายใน PEAK ผ่าน PEAK MCP

เป้าหมายที่ผู้ใช้ระบุ: `$ARGUMENTS`

ใช้ skill `peak-posting` — ทำตามขั้นตอนใน SKILL.md ทุกข้อ

## ก่อนเริ่ม — ตรวจ 4 ข้อนี้ให้ครบ ห้ามข้าม

1. ถ้าไม่ระบุโฟลเดอร์ลูกค้า/งวด → **ถามก่อน**
2. อ่าน `client-profile.md` แล้วยืนยันว่า ERP ของลูกค้ารายนี้คือ **PEAK**
   ถ้าไม่ใช่ → **หยุด** แล้วบอกผู้ใช้ว่าต้องใช้ plugin ของ ERP ที่ถูกต้อง
3. โหลดข้อมูลกิจการจาก PEAK แล้ว **เทียบชื่อกิจการและเลขผู้เสียภาษี** กับ `client-profile.md`
   ไม่ตรง → **หยุดทันที** อย่าบันทึกอะไรทั้งสิ้น
   > PEAK รองรับหลายกิจการในบัญชีผู้ใช้เดียว — ข้อนี้สำคัญกว่าที่คิด
4. input ต้องเป็นรายการที่ผ่าน `/vouch-expense` หรือ `/review-ocr` แล้ว

## เมื่อทำเสร็จ
สรุป: บันทึกใหม่กี่ใบ / ข้ามเพราะซ้ำกี่ใบ / ผิดพลาดกี่ใบ
พร้อมเตือนว่าเอกสารอยู่ใน **สถานะรออนุมัติ**
