# Dashboard จาก PEAK

ดึงตัวเลขจาก PEAK **แบบอ่านอย่างเดียว** แล้วออกเป็น `.xlsx` พร้อม KPI ตาราง กราฟ
และชีตที่มาของทุกตัวเลข

เป้าหมายที่ผู้ใช้ระบุ: `$ARGUMENTS`

ใช้ skill `peak-dashboard` — ทำตามขั้นตอนใน SKILL.md ทุกข้อ

## ก่อนเริ่ม — ตรวจ 5 ข้อนี้ให้ครบ ห้ามข้าม

1. ถ้าไม่ระบุโฟลเดอร์ลูกค้า/งวด → **ถามก่อน** อย่าเดา
2. อ่าน `client-profile.md` แล้วยืนยันว่า ERP ของลูกค้ารายนี้คือ **PEAK**
   ถ้าไม่ใช่ → **หยุด** แล้วบอกผู้ใช้ว่าต้องใช้ plugin ของ ERP ที่ถูกต้อง
3. **สำรวจ tool ของ PEAK MCP ที่โหลดอยู่จริงก่อน** แล้วสรุปให้ผู้ใช้เห็นว่าบล็อกไหนทำได้
   บล็อกไหนทำไม่ได้เพราะอะไร — **ห้ามเดาชื่อ tool**
   > 🔒 ด่านตรวจของ plugin นี้ทำงานแบบ learn-mode: tool ที่ยังไม่ได้จัดประเภทจะถูก **deny**
   > แม้เป็น tool อ่าน ถ้าเจอ deny ให้บอกผู้ใช้ให้เติมชื่อใน `hooks/peak-tools.json`
   > **"ถูก deny" ไม่ใช่ "ไม่มีข้อมูล"**
4. อ่านข้อมูลกิจการจาก PEAK แล้ว **เทียบชื่อกิจการและเลขผู้เสียภาษี** กับ `client-profile.md`
   ไม่ตรง → **หยุดทันที** — PEAK เข้าถึงหลายกิจการได้ในบัญชีเดียว
   และ Dashboard ของกิจการผิดรายอ่านดูสมเหตุสมผลทุกบรรทัด
5. ยืนยัน **งวดและงวดเทียบ** พร้อมพารามิเตอร์ที่จะส่งจริง (พ.ศ. → ค.ศ. ลบ 543)

## เมื่อทำเสร็จ
สรุป: รายได้ / ค่าใช้จ่าย / กำไรสุทธิ พร้อม % เทียบงวดก่อน · ลูกหนี้-เจ้าหนี้คงค้าง ·
**บล็อกที่ดึงไม่ได้ พร้อมแยกว่าเพราะไม่มี tool / ถูก deny / ไม่มีสิทธิ์ / error** ·
**การตรวจยอดข้ามแหล่งที่ไม่ผ่าน** · path ของไฟล์

ถ้ามีบล็อกที่ถูก deny ให้ปิดท้ายด้วยรายชื่อ tool ที่ต้องเติมใน `peak-tools.json`
เพื่อให้รันครั้งหน้าได้ครบ และย้ำว่าช่อง `ดึงไม่ได้` **ห้ามอ่านเป็นศูนย์**
