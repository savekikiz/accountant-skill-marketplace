# จับคู่รหัสผังบัญชี — PEAK

> ⚠️ **ผังบัญชีเป็นของแต่ละกิจการ ไม่ใช่ค่ากลาง**
> ต้องดึงผังบัญชีสดของกิจการนั้นจาก PEAK ทุกครั้ง แล้วเลือกจากรายการที่มีจริง
> **ห้ามใช้รหัสบัญชีจากลูกค้ารายอื่นข้ามกัน** และ **ห้ามสร้างรหัสใหม่**

---

## ลำดับความสำคัญในการตัดสิน

1. **`mapping-overrides.md` ของลูกค้ารายนั้น** — ชนะทุกกฎด้านล่าง
2. **`chart-of-accounts.xlsx` ของลูกค้า** ถ้ามีในโฟลเดอร์
3. ผังบัญชีสดที่ดึงจาก PEAK
4. กฎทั่วไปด้านล่าง
5. **ยังไม่ชัด → ถามผู้ใช้** ห้ามเดา

---

## กฎการเลือกบัญชี

### กฎที่ 1 — ดูสิ่งที่ซื้อ ไม่ใช่ชื่อผู้ขาย

### กฎที่ 2 — แยกทรัพย์สินออกจากค่าใช้จ่าย
ใช้ได้เกิน 1 ปีและมูลค่าสูง → บันทึกเป็นทรัพย์สิน (ตัดค่าเสื่อม) ไม่ใช่ค่าใช้จ่ายงวดเดียว
**เกณฑ์มูลค่าขั้นต่ำเป็นนโยบายของกิจการ** — ไม่ระบุไว้ → **ถามผู้ใช้** ห้ามตั้งเกณฑ์เอง

### กฎที่ 3 — ต้นทุน (5x ต้นทุนขาย/บริการ) vs ค่าใช้จ่าย (5x ขาย-บริหาร)
ซื้อมาส่งมอบให้ลูกค้าโดยตรง = ต้นทุน · ใช้ภายในกิจการ = ค่าใช้จ่าย

### กฎที่ 4 — ค่าเช่า vs ค่าบริการ
ผู้เช่าควบคุมการใช้ทรัพย์สินเอง = ค่าเช่า (WHT 5%)
มีคนมาให้บริการด้วย = ค่าบริการ (WHT 3%)
**ข้อนี้กระทบอัตรา WHT** ตัดสินผิดแล้วต้องออกหนังสือรับรองใหม่

### กฎที่ 5 — บัญชี "ค่าใช้จ่ายเบ็ดเตล็ด" คือทางออกสุดท้าย
ถ้าจะใช้ ต้องถามผู้ใช้ก่อนเสมอ

## กลุ่มบัญชีค่าใช้จ่ายที่พบบ่อยในกิจการไทย

> ตารางนี้ใช้ **ระบุกลุ่ม** เพื่อไปหารหัสจริงในผังบัญชีของกิจการ
> เลขรหัสที่แสดงเป็นรูปแบบที่พบบ่อยเท่านั้น **ไม่ใช่รหัสมาตรฐานที่ทุกกิจการใช้เหมือนกัน**

| กลุ่ม | ตัวอย่างชื่อบัญชี | WHT ที่มักเกี่ยวข้อง |
|---|---|---|
| ค่าบริการ | ค่าบริการ, ค่าบริการอื่นๆ | 3% |
| ค่าที่ปรึกษา / วิชาชีพ | ค่าที่ปรึกษา, ค่าบริการวิชาชีพ, ค่าทำบัญชี, ค่าสอบบัญชี | 3% |
| ค่าจ้างทำของ | ค่าจ้างผลิต, ค่าจ้างทำของ, ค่าออกแบบ | 3% |
| ค่าโฆษณา | ค่าโฆษณา, ค่าการตลาด | 2% |
| ค่าขนส่ง | ค่าขนส่ง, ค่าขนส่งสินค้า | 1% (เฉพาะผู้ประกอบการขนส่ง) |
| ค่าเช่า | ค่าเช่าสำนักงาน, ค่าเช่าอุปกรณ์, ค่าเช่ายานพาหนะ | 5% |
| ค่าสาธารณูปโภค | ค่าไฟฟ้า, ค่าน้ำประปา, ค่าโทรศัพท์, ค่าอินเทอร์เน็ต | ปกติไม่หัก |
| ซ่อมแซมบำรุงรักษา | ค่าซ่อมแซม, ค่าบำรุงรักษา | 3% (ถ้าเป็นค่าจ้างทำของ) |
| วัสดุสิ้นเปลือง | วัสดุสำนักงาน, เครื่องเขียน | ไม่หัก (ซื้อของ) |
| ซอฟต์แวร์ / IT | ค่าบริการ IT, ค่าซอฟต์แวร์รายเดือน | 3% |
| ค่าธรรมเนียม | ค่าธรรมเนียมธนาคาร, ค่าธรรมเนียมวิชาชีพ | ค่าธรรมเนียมธนาคารไม่หัก |
| เดินทาง | ค่าเดินทาง, ค่าที่พัก, ค่าน้ำมันเชื้อเพลิง | ไม่หัก |
| รับรอง | ค่ารับรอง | ไม่หัก · **ขอคืน VAT ไม่ได้** |
| ทรัพย์สิน | อุปกรณ์คอมพิวเตอร์, เครื่องใช้สำนักงาน, ยานพาหนะ | ไม่หัก (ซื้อของ) |

**คอลัมน์ WHT เป็นแนวโน้มที่พบบ่อย ไม่ใช่กฎตายตัว** — ตัดสินจริงต้องดูว่า
*จ่ายเพื่ออะไร* และ *ผู้รับเป็นใคร* อัตราจริงดูที่
`accounting-office-core` → `skills/wht-prep/references/wht-rates.md`

## จุดที่ต้องระวังเป็นพิเศษ

| สถานการณ์ | เส้นแบ่ง |
|---|---|
| ค่าซ่อมแซม ↔ ส่วนปรับปรุงทรัพย์สิน | ทำให้กลับสู่สภาพเดิม = ค่าใช้จ่าย · ทำให้ดีขึ้น/อายุยาวขึ้น = เพิ่มราคาทรัพย์สิน |
| ค่ารับรอง ↔ สวัสดิการพนักงาน | เลี้ยงลูกค้า = ค่ารับรอง (ขอคืน VAT ไม่ได้ และหักภาษีได้จำกัด) · เลี้ยงพนักงาน = สวัสดิการ |
| ค่าน้ำมันรถยนต์นั่งของกิจการ | **ขอคืน VAT ไม่ได้** ตามมาตรา 82/5 — ต้องบันทึกรวม VAT เป็นค่าใช้จ่าย |
| มัดจำ / เงินประกัน | เป็น **สินทรัพย์** ไม่ใช่ค่าใช้จ่าย จนกว่าจะรับรู้จริง |
| จ่ายล่วงหน้าข้ามงวด (ประกัน ค่าเช่ารายปี) | ควรเป็นค่าใช้จ่ายจ่ายล่วงหน้า แล้วตัดเข้างวด — **ถามผู้ใช้** |

3 กรณีแรกกระทบภาษีโดยตรง — เมื่อไม่แน่ใจ **ถาม อย่าเดา**
