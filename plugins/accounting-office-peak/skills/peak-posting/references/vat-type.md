## ประเภท VAT ที่ต้องเลือกให้ถูก

| ประเภท | ใช้เมื่อ | ผลต่อรายงานภาษีซื้อ |
|---|---|---|
| **VAT 7%** | ซื้อจากผู้ประกอบการจด VAT มีใบกำกับภาษีเต็มรูป | เข้ารายงานภาษีซื้อ ขอคืนได้ |
| **VAT 0%** | ซื้อ/นำเข้าที่ใช้อัตรา 0% | เข้ารายงาน แต่ไม่มียอดภาษี |
| **ยกเว้น VAT / ไม่มี VAT** | ผู้ขายไม่จด VAT, สินค้าที่ได้รับยกเว้นตามมาตรา 81 | ไม่เข้ารายงานภาษีซื้อ |
| **VAT ที่ขอคืนไม่ได้** | มีใบกำกับภาษี แต่กฎหมายห้ามขอคืน | **ต้องรวม VAT เป็นต้นทุน/ค่าใช้จ่าย** |

> ชื่อตัวเลือกจริงในหน้าจอ PEAK อาจใช้คำต่างจากนี้
> ให้ดูตัวเลือกที่ระบบมีจริง แล้วจับคู่ตามความหมาย **ห้ามเดา**

## รายการที่มีใบกำกับภาษี แต่ขอคืน VAT ไม่ได้ (มาตรา 82/5)

**ต้องตั้งเป็น "ขอคืนไม่ได้" และบันทึกยอดรวม VAT เป็นค่าใช้จ่าย**

| กรณี | อ้างอิง |
|---|---|
| ใบกำกับภาษี**อย่างย่อ** (ร้านสะดวกซื้อ ปั๊มน้ำมัน) | ม.82/5(6) |
| ค่ารับรอง | ม.82/5(4) |
| รถยนต์นั่ง/รถโดยสารไม่เกิน 10 ที่นั่ง รวมค่าน้ำมันและค่าซ่อม | ม.82/5(6) + ประกาศอธิบดี ฉบับที่ 42 |
| ใบกำกับภาษีที่มีรายการไม่ครบตามมาตรา 86/4 | ม.82/5(2) |
| ภาษีซื้อที่ไม่เกี่ยวกับการประกอบกิจการ | ม.82/5(3) |

**ถ้าลูกค้าไม่ได้จดทะเบียน VAT** (ดู `client-profile.md`) → **ทุกรายการบันทึกยอดรวม VAT
เป็นค่าใช้จ่ายทั้งหมด** ไม่มีภาษีซื้อให้ขอคืน ถ้าเจอรายการที่แยก VAT ไว้ ให้ทักผู้ใช้

## ราคารวม VAT หรือไม่รวม — ต้องถามทุกครั้ง

ใบกำกับภาษีไทยที่แยกบรรทัด `รวมเงิน` + `ภาษีมูลค่าเพิ่ม 7%` + `จำนวนเงินทั้งสิ้น`
= ราคา **ยังไม่รวม VAT**

ยืนยันด้วยคณิตศาสตร์ก่อนตั้งค่า:
```
รวมเงิน × 1.07 = จำนวนเงินทั้งสิ้น   →  ยังไม่รวม VAT
```

**ห้ามตั้งค่านี้เองโดยไม่ถาม** — ตั้งผิดทำให้ยอดเพี้ยนประมาณ 7% ทั้งใบ

## สูตรคำนวณ

### ไม่มี VAT
```
ยอดค่าใช้จ่าย  = จำนวนเงิน
WHT            = จำนวนเงิน × อัตรา WHT
ยอดจ่ายสุทธิ   = จำนวนเงิน − WHT
```

### มี VAT 7% — เอกสารระบุยอดก่อน VAT
```
ยอดก่อน VAT   = จำนวนเงิน
VAT           = ยอดก่อน VAT × 0.07
ยอดรวม        = ยอดก่อน VAT + VAT
WHT           = ยอดก่อน VAT × อัตรา WHT      ← ฐานคือยอดก่อน VAT เสมอ
ยอดจ่ายสุทธิ  = ยอดรวม − WHT
```

### มี VAT 7% — เอกสารระบุยอดรวม VAT แล้ว
```
ยอดก่อน VAT   = ยอดรวม ÷ 1.07
VAT           = ยอดรวม − ยอดก่อน VAT
WHT           = ยอดก่อน VAT × อัตรา WHT
ยอดจ่ายสุทธิ  = ยอดรวม − WHT
```

**อย่าใช้ `ยอดรวม × 0.07` เพื่อหา VAT** — ได้ค่าเกินจริงประมาณ 7%

### ตัวอย่างตรวจเอง — ค่าบริการ 10,000 บาท VAT 7% WHT 3%
```
ยอดก่อน VAT   = 10,000.00
VAT           =    700.00
ยอดรวม        = 10,700.00
WHT           =    300.00   (10,000 × 3% — ไม่ใช่ 10,700 × 3% = 321)
ยอดจ่ายสุทธิ  = 10,400.00
```

## ตรวจก่อนบันทึก

- [ ] ประเภท VAT ตรงกับประเภทเอกสารที่ได้รับจริง
- [ ] ใบกำกับภาษีอย่างย่อ → ตั้งเป็นขอคืนไม่ได้
- [ ] ลูกค้าไม่จด VAT → ไม่แยก VAT ทุกรายการ
- [ ] ตั้งค่า "ราคารวม VAT" ตามที่ **ผู้ใช้ยืนยัน** ไม่ใช่ที่ระบบเดา
- [ ] `ยอดก่อน VAT × 0.07 = VAT` (±0.02) และ `ยอดก่อน VAT + VAT = ยอดรวม`
- [ ] WHT คำนวณจากยอดก่อน VAT
- [ ] เลขผู้เสียภาษีผู้ขายครบ 13 หลักและผ่าน checksum — ไม่งั้นรายงานภาษีซื้อจะมีปัญหาตอนยื่น
