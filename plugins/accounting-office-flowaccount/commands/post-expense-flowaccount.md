# บันทึกค่าใช้จ่ายเข้า FlowAccount

นำรายการที่ **ผ่านการตรวจแล้ว** ไปสร้างเป็นเอกสารค่าใช้จ่ายใน FlowAccount ผ่าน FlowAccount MCP

เป้าหมายที่ผู้ใช้ระบุ: `$ARGUMENTS`

ใช้ skill `flowaccount-posting` — ทำตามขั้นตอนใน SKILL.md ทุกข้อ

## ก่อนเริ่ม — ตรวจ 4 ข้อนี้ให้ครบ ห้ามข้าม

1. ถ้าไม่ระบุโฟลเดอร์ลูกค้า/งวด → **ถามก่อน**
2. อ่าน `client-profile.md` แล้วยืนยันว่า ERP ของลูกค้ารายนี้คือ **FlowAccount**
   ถ้าไม่ใช่ → **หยุด** แล้วบอกผู้ใช้ว่าต้องใช้ plugin ของ ERP ที่ถูกต้อง
3. โหลดข้อมูลบริษัทจาก FlowAccount แล้ว **เทียบชื่อบริษัทและเลขผู้เสียภาษี** กับ `client-profile.md`
   ไม่ตรง → **หยุดทันที** อย่าบันทึกอะไรทั้งสิ้น
   > 🔒 ข้อนี้ hook บังคับด้วย: ถ้ายังไม่ได้โหลดข้อมูลบริษัท หรือเลขผู้เสียภาษีไม่ตรงกับ
   > `client-profile.md` การสร้างเอกสารจะถูก deny ทุกกรณี
4. input ต้องเป็นรายการที่ผ่าน `/vouch-expense` หรือ `/review-ocr` แล้ว
   ถ้าผู้ใช้ให้ไฟล์ดิบที่ยังไม่ได้ตรวจ ให้ทักก่อนว่าควรตรวจก่อน

## เมื่อทำเสร็จ
สรุป: บันทึกใหม่กี่ใบ / ข้ามเพราะซ้ำกี่ใบ / ผิดพลาดกี่ใบ
พร้อมเตือนว่าเอกสารอยู่ใน **สถานะรออนุมัติ** และยังไม่ได้แนบไฟล์
