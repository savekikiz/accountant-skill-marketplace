# Dashboard จาก FlowAccount

ดึงตัวเลขจาก FlowAccount **แบบอ่านอย่างเดียว** แล้วออกเป็น `.xlsx` พร้อม KPI ตาราง กราฟ
และชีตที่มาของทุกตัวเลข

เป้าหมายที่ผู้ใช้ระบุ: `$ARGUMENTS`

ใช้ skill `flowaccount-dashboard` — ทำตามขั้นตอนใน SKILL.md ทุกข้อ

## ก่อนเริ่ม — ตรวจ 4 ข้อนี้ให้ครบ ห้ามข้าม

1. ถ้าไม่ระบุโฟลเดอร์ลูกค้า/งวด → **ถามก่อน** อย่าเดา
2. อ่าน `client-profile.md` แล้วยืนยันว่า ERP ของลูกค้ารายนี้คือ **FlowAccount**
   ถ้าไม่ใช่ → **หยุด** แล้วบอกผู้ใช้ว่าต้องใช้ plugin ของ ERP ที่ถูกต้อง
3. โหลดข้อมูลบริษัทจาก FlowAccount แล้ว **เทียบชื่อกิจการและเลขผู้เสียภาษี** กับ `client-profile.md`
   ไม่ตรง → **หยุดทันที** — Dashboard ของกิจการผิดรายอ่านดูสมเหตุสมผลทุกบรรทัด
4. ยืนยัน **งวดและงวดเทียบ** พร้อมพารามิเตอร์ที่จะส่งจริง (พ.ศ. → ค.ศ.)
   ถ้าไม่ระบุงวดเทียบ ให้ใช้เดือนก่อนหน้าแล้วบอกผู้ใช้ว่าใช้อะไร
