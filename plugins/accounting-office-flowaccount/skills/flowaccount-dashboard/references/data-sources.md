# แหล่งข้อมูลของแต่ละบล็อก — FlowAccount MCP

> ⚠️ **ชื่อ tool ในไฟล์นี้เป็นชื่อที่พบในเวอร์ชันที่ทดสอบไว้ ณ วันที่จัดทำ**
> ก่อนใช้ ให้ดูรายชื่อ tool ที่โหลดอยู่จริงในเซสชันก่อนเสมอ (Step 0 ของ SKILL.md)
> ชื่อไม่ตรง → ใช้ชื่อที่มีจริง · หา tool ของบล็อกไหนไม่เจอ → บล็อกนั้นเป็น `unavailable`
> **ห้ามเดาชื่อ tool และห้ามข้ามบล็อกไปเงียบๆ**

ชื่อ server มีสองแบบ ขึ้นกับว่าต่อผ่านอะไร: `mcp__flowaccount__…` (`.mcp.json` ของ plugin)
หรือ `mcp__claude_ai_FlowAccount_MCP__…` (connector ของ claude.ai) — ตารางนี้เขียนแบบตัด prefix ออก

## 1. บล็อก → tool

| บล็อก (`id`) | ชีต | tool | หมายเหตุ |
|---|---|---|---|
| `company` | (หัวไฟล์) | `company_settings__load` | ยืนยันกิจการปลายทาง — **ต้องเรียกก่อนทุกบล็อก** |
| `pl` | งบกำไรขาดทุน | `accounting__get_profit_loss` | เรียก 2 ครั้ง: งวดนี้ และงวดเทียบ |
| `balance` | งบแสดงฐานะการเงิน | `accounting__get_balance_sheet` | ยอดยกมา/ยอดคงเหลือ ณ สิ้นงวด |
| `trial_balance` | งบทดลอง | `accounting__get_trial_balance` | ใช้ตรวจว่าเดบิต = เครดิต |
| `ar_aging` | อายุลูกหนี้ | `accounting__get_ar_aging` | ถ้าไม่มี ให้ลอง `overview__get_aging_summary` |
| `ap_aging` | อายุเจ้าหนี้ | `accounting__get_ap_aging` | เหมือนกัน |
| `outstanding_in` | ลูกหนี้คงค้าง | `overview__get_outstanding_invoices` | รายใบที่ยังไม่ได้รับชำระ |
| `outstanding_out` | เจ้าหนี้คงค้าง | `overview__get_outstanding_payments` | รายใบที่ยังไม่ได้จ่าย |
| `sales` | ยอดขาย | `sales__list_tax_invoices`, `sales__list_cash_invoices`, `sales__list_receipts` | สรุปเป็นยอดรวม/จัดอันดับ ไม่ใส่ทุกใบ |
| `sales_journal` | ยอดขาย | `accounting__list_sales_journal` | ใช้เป็นแหล่ง ข ของการตรวจยอดรายได้ |
| `expense` | ค่าใช้จ่าย | `expense__list_expenses` | + `expense__list_business_categories` เพื่อจัดกลุ่มหมวดหมู่ |
| `purchase_journal` | ค่าใช้จ่าย | `accounting__list_purchase_journal` | แหล่ง ข ของการตรวจยอดค่าใช้จ่าย |

| `channels` | เงินรับ-จ่าย | `company_settings__list_payment_channels` | ใช้แปลรหัสช่องทางเป็นชื่อ |
| `top_customers` | ลูกค้ารายใหญ่ | จาก `sales__list_*` + `contacts__list` | จัดอันดับเอง — กำกับว่าเป็นค่าที่คำนวณต่อ |
| `top_vendors` | ผู้ขายรายใหญ่ | จาก `expense__list_expenses` | เหมือนกัน |

## 2. แปลงงวดให้เป็นพารามิเตอร์

FlowAccount MCP รับค่าช่วงเวลาได้หลายรูป — **ส่งเองทุกครั้ง อย่าพึ่งค่า default**
เพราะค่า default ของแต่ละ tool ไม่เหมือนกัน

| ผู้ใช้พูด | ส่งเป็น |
|---|---|
| เดือนนี้ | `this_month` |
| เดือนก่อน | `last_month` |
| ปีนี้ / ปีก่อน | `this_year` / `last_year` |
| 3 เดือนล่าสุด | `last_3_months` |
| งวด 2569-09 (ก.ย. 2569) | `2026-09` |
| ไตรมาส 3/2569 | `2026-07-01_2026-09-30` |
| วันเดียว 15 ก.ย. 2569 | `2026-09-15` |
| ไม่ได้ระบุช่วงเวลา | **ถามก่อน** — การไม่ส่งค่าหมายถึง "ทุกรายการ" ไม่ใช่ "เดือนนี้" |

**ปี พ.ศ. → ค.ศ. ลบ 543 เสมอ** งวดที่สำนักงานเรียก `2569-09` คือ `2026-09` ในพารามิเตอร์
ให้แสดงทั้งสองแบบให้ผู้ใช้ยืนยันก่อนดึง แล้วบันทึกค่าที่ส่งจริงลง `source.params`
ของทุกบล็อก — ปี พ.ศ./ค.ศ. สลับกันคือวิธีที่ง่ายที่สุดที่จะได้รายงานของเดือนที่ไม่ได้ขอ

งวดเทียบ: ถ้าผู้ใช้ไม่ระบุ ให้ใช้ **เดือนก่อนหน้า** สำหรับงวดรายเดือน
และ **ปีก่อนหน้าเดือนเดียวกัน** ถ้าธุรกิจมีฤดูกาลชัด (ผู้ใช้เป็นคนบอก ไม่ใช่เดาเอง)

## 3. กับดักที่เจอจริง

1. **รายงานที่ต้องรอประมวลผล** — บาง tool คืนสถานะ "กำลังสร้างรายงาน" ก่อนคืนตัวเลข
   ถ้ามี `accounting__get_report_status` ให้ตรวจสถานะก่อนแล้วค่อยอ่านผล
   **ห้ามอ่านค่าจาก response ที่ยังไม่พร้อมแล้วเอาไปใส่ในไฟล์**
2. **`list_*` มีการแบ่งหน้า** — ยอดรวมจากหน้าเดียวคือยอดรวมที่ผิด
   ดึงให้ครบ หรือถ้าดึงไม่ครบให้ `status: "partial"` พร้อมจำนวนหน้าที่ดึงได้
3. **เอกสารหลายสถานะ** — ร่าง / รออนุมัติ / อนุมัติแล้ว / ยกเลิก
   ต้องรู้ว่ายอดที่ได้มารวมสถานะไหน แล้วเขียนไว้ใน `meta.notes` ของ data pack
4. **เอกสารฝั่งขายมีหลายชนิดที่ทับซ้อนกัน** — ใบกำกับภาษี ใบเสร็จ ใบแจ้งหนี้ ใบเสนอราคา
   **นับซ้ำได้ง่ายมาก** ให้เลือกชนิดเอกสารที่ถือเป็น "ยอดขาย" ของลูกค้ารายนั้น
   (ดู `mapping-overrides.md`) แล้วระบุไว้ในหัวชีต
5. **ใบลดหนี้/ใบเพิ่มหนี้** (`sales__list_credit_notes` / `list_debit_notes`)
   ถ้าไม่หักออก ยอดขายจะสูงเกินจริง — ต้องดึงมาด้วยหรือระบุว่าไม่ได้หัก
6. **งบกำไรขาดทุนกับสมุดรายวันไม่ตรงกันเป็นเรื่องปกติ** เมื่อเกณฑ์การรับรู้ต่างกัน
   หรือมีรายการปรับปรุง — รายงานผลต่าง **ห้ามกลบ**
7. **กิจการหลายสกุลเงิน** — `accounting__get_exchange_rate` มีไว้ให้ดูอัตรา
   แต่ skill นี้ไม่แปลงสกุลเงิน ทำเฉพาะ THB แล้วแจ้งข้อจำกัด
8. **ยอดใน Dashboard ไม่ใช่ยอดที่ยื่นภาษี** — ฐานภาษีมีข้อแตกต่างของตัวเอง
   ห้ามให้ผู้ใช้เข้าใจว่าเอาไปยื่นได้
